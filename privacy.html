Privacy

What the current prototype stores and sends when you use the learning features.

Practice history

Recent practice entries are stored in your browser's local storage on the device you use. The site does not provide an account-based history in the current version. Clearing browser site data can remove the saved history.

Speech input

Voice input uses the speech-recognition capability provided by your browser. The exact processing of speech data depends on the browser and service provider. Check your browser's privacy documentation before using voice input for sensitive information.

Translation requests

The current prototype sends the text you submit to the translation endpoint used by the JavaScript application. Do not enter passwords, identification numbers, health information or other sensitive personal information into the translator. For production, the translation integration should be replaced with an official API behind a controlled backend.

Weather

The weather section requests current weather data from Open-Meteo for Oslo and Bergen. See Open-Meteo's terms for information about the service.

Contact

Contact information is published on the developer contact page. Please avoid sending sensitive personal information by email.
