About Learn Norwegian

A small, voice-first learning tool focused on everyday Norwegian Bokmål practice.

What the app does

Learn Norwegian lets you speak or type a short sentence and then practise the translated result. The main flow is designed around short repetitions: say something, read the Bokmål sentence, hear it, and repeat it.

Designed for clarity

The interface uses a light, structured public-service style: clear hierarchy, readable typography, strong focus states, simple borders and task-focused language. The design takes inspiration from accessible Norwegian public-sector interface principles without copying NAV or UDI branding.

Technology

  • HTML5 and CSS for the user interface.
  • JavaScript for speech input, browser speech synthesis, translation requests, local practice history and weather updates.
  • Open-Meteo for the live Oslo and Bergen weather section.

Important limitations

Speech recognition and speech synthesis depend on the browser and device. Translation is a prototype feature and should not be treated as a certified or professional translation service. For a production application, the translation call should be moved behind a backend and replaced with an official translation API.

Independent project

Learn Norwegian is an independent learning project. It is not affiliated with, endorsed by, or operated by NAV, UDI, the Norwegian government or any Norwegian public authority.
