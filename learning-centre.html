Make it a habit

A simple 5-minute study routine

  1. Review five flashcards. Say each word out loud before revealing its meaning.
  2. Mark honestly. Use “I know this” only if you recalled the meaning without peeking; difficult words can be reviewed again.
  3. Take the short quiz. Aim to remember the meaning, not just recognise the screen.
  4. Return tomorrow. A short repeat session is more sustainable than an occasional long session.

This tool uses a simple self-tracked review list; it is not a scientifically validated spaced-repetition algorithm.
