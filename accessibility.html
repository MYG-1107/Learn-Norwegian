Accessibility

The site is designed to be usable with a keyboard, different screen sizes and reduced-motion settings.

Current accessibility measures

  • Semantic HTML landmarks for header, navigation, main content and footer.
  • A skip link lets keyboard users move directly to the main content.
  • Visible keyboard focus indicators are provided for links, buttons, inputs and menus.
  • Interactive status and translation areas use live-region semantics where useful.
  • Text uses readable sizes, high-contrast borders and a responsive layout.
  • Reduced-motion preferences are respected.
  • Images have meaningful alternative text where an image communicates information.

Known limitations

Speech recognition and speech synthesis remain dependent on browser capabilities and available voices. Live translation and weather also require JavaScript and a network connection.

Feedback

Use the developer contact page to report an accessibility problem. Please describe the page, the device/browser and what you expected to happen.
